## 0. 开始前先做三件事

1. **填 Key**：设置 → 粘贴阶跃星辰 API Key → 「保存并测试」，看到「连接成功」。
2. **建一个测试题库**：题库管理 → 新建，名字叫「测试-八年级数学」。所有测试题都存这里，测完一键批量删掉，不脏你的正式题库。
3. **先导出一次现状**：设置 → 导出全部数据（如果题库已经有你自己录的题，这一步别省，导入样例会覆盖）。

> 想边测边看后台发生了什么：双击 `开发模式启动-Windows.bat`，另开一个窗口看它的输出，每次调用模型都会打印耗时和 tokens。

## 2. 三轮测试路线

### 第一轮：冒烟（确认「能跑通」）

按顺序点一遍，任何一步报错就先停下来修，后面的不用测：

1. 智能录题 → 拖入 `单题-选择题.jpg` → 单题模式 → 开始识别
2. 结果卡出现 → 勾选 → 保存到题库
3. 题库管理 → 看到这道题 → 点「生成试卷」→ 打印预览能出来
4. 讲义排版 → +章节 → 从题库选题 → 插入刚才那道题 → 打印 / 导出 PDF
5. 数据统计 → 本月调用次数 ≥ 1、花费 > 0、平均响应有数字

## 3. 判定口径

一份结果算「通过」，要同时满足：

1. **题数对**：不多不少（允许 ±1 的题号串行误差，不允许整题丢失或凭空多出）。
2. **题干不丢信息**：分数、根号、上下标、角度、化学式这类符号，允许写法不同（`√3` / `sqrt3` / `√(3)` 都行），但**不能变成别的意思**（`CO2` 变 `CO` 就算失败）。
3. **选项不串**：A/B/C/D 的内容与图上对应，顺序不能乱。
4. **答案不乱填**：图上没答案就是空；不许把学生手写、例题解析、页脚文字当答案。
5. **不崩**：任何一步都不应该白屏、卡死、需要重启程序。

失败时记清三件事：**哪个文件 + 哪一步 + 实际出现了什么**（截图最好）。有这三样我能直接定位是提示词问题、压缩参数问题，还是版面理解问题。

## 4. 预期内的不完美（先别当 bug）

| 现象 | 说明 |
|---|---|
| 图形题题干只有 `[图]` 或「如图」 | 现阶段文字模型不描述图形，靠老师自己补图 |
| 手写体识别有错字 | 视觉模型对手写能力有限 |
| 旋转 90°/180° 的图识别乱 | 没做方向矫正 |
| 表格题变成一串数字 | 表格结构提取能力有限，能读到数字即可 |
| 极长讲义（3000 字以上）AI 分节会被截断 | 单次输出上限 6144 tokens，可分两次导入 |
| 同一题重复保存被跳过 | 去重逻辑，避免录两遍 |
| 首次识别比后续慢 1～2 秒 | 首次要建立连接 |

## 6. 测出问题后怎么给我

把这三样发我，改起来最快：

1. **原始图片/文件**（就是测试材料里那个文件名）
2. **程序实际返回的题卡**（截图，或浏览器 F12 → Network → 看 `/api/recognize` 的 response）
3. **期望是什么**（比如「这题答案应该是空，结果填了 20°」）

如果怀疑是提示词问题，我可以直接改 `lib\stepfun.js` 里的 `recognizePrompt()` 再重打包，不用改前端。
