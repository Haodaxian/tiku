# 题卡 JSON 字段说明

顶层必须是对象：`{"questions":[...]}`。也接受直接给数组 `[...]`，但推荐带 `questions` 外壳。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `no` | string | 否 | 纸面题号，如 `"12"`、`"(2)"`；没有填空串 |
| `stem` | string | 是 | 题干纯文本，保留原文，填空写 `____`（4 个下划线） |
| `type` | string | 是 | 单选题 / 多选题 / 填空题 / 判断题 / 解答题 / 计算题 / 应用题 / 实验探究题 / 简答题 / 阅读理解题 / 图表分析题 / 作文题 / 完形填空题 / 其他 |
| `options` | array | 选择题必填 | `[{"key":"A","text":"2√7"}]`，非选择题给 `[]` |
| `answer` | string | 否 | 选择题写字母（`"A"`、`"AC"`）；判断题写「正确/错误」；其余写答案原文 |
| `analysis` | string | 否 | 解析原文；不需要就空串 |
| `knowledge` | string[] | 否 | **1-10 个**知识点短词；考查多个知识点时全部打上 |
| `difficulty` | string | 是 | 简单 / 中等 / 较难，判断不出填「中等」 |
| `subject` | string | 否 | 如 `"初中数学"`、`"高中物理"` |
| `grade` | string | 否 | 如 `"八年级"`、`"高三"` |
| `year` | string | 否 | 如 `"2024"` |
| `region` | string | 否 | 如 `"江苏南京"` |
| `source` | string | 否 | 出处，如 `"2024·某某中学期中"` |
| `chapter` | string | 否 | 教材章节，如 `"第21章 一元二次方程"` |
| `tags` | string[] | 否 | 自定义标签，最多 12 个 |
| `figures` | array | 否 | 见下 |
| `stemHtml` | string | 否 | 富文本题干；一般不用，留给系统内部 |

顶层还可以额外带一个 `answers` 数组（与题目一一对应、顺序一致），系统会优先用它回填每题答案。

## figures

```json
{"label":"图1","desc":"直角三角形，直角在 C，AC=3、BC=4","url":"data:image/png;base64,iVBORw0KGgo..."}
```

- `label`：与题干里的 `[图1]` 占位符对应。
- `desc`：文字描述图形。**必须写清楚**，因为导入后用户可能只看到图、也可能看不到图。
- `url`：**可选**。
  - 写成 base64 data URI（`data:image/png;base64,....`）时，系统在导入时自动解码存到本地图片目录，题卡里只留本地路径，数据库不会膨胀。单张 base64 控制在 1.2MB 以内，一题最多 8 张。
  - 也可以写已有的本地路径（`/uploads/xxx.png`）。
  - **拿不到原图就整个字段留空**，只给 `label` + `desc`，导入后在系统里框选或上传补图。
- `bbox`：外部生成时不要给，系统内置识图会自动补。

## 常见错误

| 现象 | 原因 |
|---|---|
| 导入后题型全是「其他」 | `type` 写了「选择题」「单项选择」等非标准词；必须用「单选题」 |
| 难度全变「中等」 | `difficulty` 写成「易」「难」「easy」；必须用「简单/中等/较难」 |
| 选项丢失 | `options` 写成字符串数组 `["2√7","4"]`；系统能兜底，但推荐对象数组 |
| 题目被跳过 | `stem` 为空；题干必须非空 |
| 公式乱码 | 用了 LaTeX 或 `$...$`；改用 `x²`、`√3`、`a/b` |
| 填空处看不到横线 | 抽取时横线被吞了；补成 `____`（4 个下划线），别用 `……` |
| 图形没显示 | 只给了 `label`+`desc` 却没有 `url`；有原图就内嵌 base64 data URI |
| db.json 暴涨 | 直接把 base64 存进了题卡 `url`；系统导入时会自动落盘，不要自己存 |
| 答案串位 | 答案没写进每题自己的 `answer`；必须一题一条、顺序一致 |
| 知识点只打了一个 | 一题其实考多个点；`knowledge` 要 1-10 个，全部打上 |
